# ConcertMVP

Две реализации главной страницы Концертного центра «Сириус»:

- [Astro + React](https://miggrabbid.github.io/ConcertMVP/astro/)

Обе версии собираются и публикуются одним workflow `.github/workflows/deploy-pages.yml`.
